# Spam-Email-Classification
Machine Learning-based Spam Email Classification using Naive Bayes and Natural Language Processing (NLP). This project detects and classifies emails as Spam or Ham using Python and Scikit-learn.

## Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) to classify emails as Spam or Ham. It uses the Naive Bayes algorithm to detect unwanted spam messages based on text features.
